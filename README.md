# Youtube-Embed-Json-Music-Playlist-System-BRD_VR
This is a simple html and local python server based project I have put to port 8081. It allows you to create json playlist files, save them, and load them based on a free Youtube embed iframe. Straight.html is where you hard code your own playlists that cannot be edited on the page itself. This version was made for VR where file uploads are wacky.
