Check Live Playlists

Linked playlists are checked against their own YouTube playlist. Set "custom": true in a playlist JSON to skip the API and pass that file's fields and song rows through both ZIP exports unchanged. Duplicate IDs, possible same-song uploads, and saved entries absent from the API are kept and flagged for review; nothing is automatically removed.

Full Restore exports only the entries returned by the API, in API order. For matching video IDs, it reuses saved titles and artists when present; otherwise it uses the API metadata. Review and acknowledge flagged issues before either ZIP can download.
